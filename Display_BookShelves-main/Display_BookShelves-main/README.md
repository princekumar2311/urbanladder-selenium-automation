#Display Bookshelves Automation Testing
Overview

This project is an automated testing framework developed for the Urban Ladder website using Java, Selenium WebDriver, and TestNG. The framework automates key user workflows and validates important functionalities such as searching bookshelves, applying filters, navigating menus, and interacting with gift card features.

Objectives
Automate repetitive website testing tasks.
Validate core functionalities of the Urban Ladder website.
Improve test efficiency and reliability.
Follow industry-standard automation testing practices.
Features Tested
Bookshelves search functionality

The project follows the Page Object Model (POM) design pattern to improve:

Code reusability
Maintainability
Scalability
Test readability
Project Structure
Pages – Contains page classes and web element locators.
Test Cases – Contains automated test scripts.
Utilities – Common helper methods and reusable components.
Reports – Test execution reports and logs.
Resources – Configuration files and test data.
